---
title: "对象"
description: "FSP 操作中的容器类型、物理属性和状态"
---

FSP 中的对象是设备能够识别、处理或观测的容器。容器定义必须给出可用于接口校验的物理属性和状态，不能只给出内部业务名称。

## 对象原理

对象描述的不是某台设备中的编号，而是设备操作所面对的实际实验器皿。FSP 使用稳定的容器类型、物理属性和当前状态，使编译/解释器、仿真器、执行器以及不同设备能够判断同一容器是否可识别、可容纳、可定位和可操作。

容器类型目录可以扩展，但每个名称必须对应明确的器皿形态。不同容量、口型、底型或材质会影响定位、夹持、容量和工艺兼容性时，应定义为不同类型或不同规格。

## 容器分类

| 分类 | 容器示例 | 重点描述的数据 |
| --- | --- | --- |
| 瓶类 | 西林瓶、色谱进样瓶、留样瓶、粉末瓶、耐热瓶、耐压瓶、耐腐蚀瓶、浓缩瓶、核磁溶剂瓶、核磁原料瓶 | 瓶身与瓶口直径、高度、底型、口型、盖型、材质、标称容积和最大工作容积 |
| 管类 | 15 mL 离心管、50 mL 离心管、试管、耐压反应管、核磁管 | 管径、高度、底型、口型、材质、标称容积、耐压或耐温范围 |
| 孔板类 | 24 孔板、96 孔板、电镜样品板、质谱样品板 | 长宽高、孔数、行列布局、单孔形状、孔径、孔深、单孔容积和板体材质 |
| 坩埚类 | 高温煅烧坩埚、XRD 坩埚、管式炉处理坩埚、管式炉反应坩埚 | 外形、口径、底径、长度、宽度、高度、材质、耐温范围和工作容积 |
| 反应容器 | 烧杯、高压釜 | 内外径、高度、开口与密封形式、材质、标称容积、最大工作容积、耐压和耐温范围 |
| 光学与表征容器 | 3 mL 比色皿、5 mL 比色皿、石英基底片、红外基底片、玻璃片、荧光玻片、光刻片、玻碳片 | 长宽厚或直径、光程、材质、表面形态、可用区域和样品承载状态 |
| 进样与转移容器 | 固体进样料斗、料斗、中转原料瓶 | 开口尺寸、长宽高、材质、容量、出口形态和当前装载状态 |

该分类用于统一语义，不限制实现只支持表中器皿。设备接口只需声明自己实际支持的容器类型和规格。

## 属性要求

| 属性组 | 典型字段 | 作用 |
| --- | --- | --- |
| 身份 | `object_type_id`、`container_id`、`name`、`category` | 区分容器类型与具体实例 |
| 形状 | `shape`、`bottom_shape`、`opening_shape` | 判断定位、夹持、倾倒和工具兼容性 |
| 尺寸 | `length_mm`、`width_mm`、`height_mm`、`outer_diameter_mm`、`inner_diameter_mm`、`opening_diameter_mm` | 判断空间、夹具和运动边界 |
| 容量 | `nominal_volume_mL`、`max_working_volume_mL`、`remaining_volume_mL` | 校验加样、取样和溢出风险 |
| 材质 | `material`、`surface_material` | 判断化学、温度、光学和机械兼容性 |
| 结构 | `closure_type`、`well_count`、`rows`、`columns`、`well_volume_mL` | 描述瓶盖、多孔板等专用结构 |
| 状态 | `container_status`、`sample_status`、`sample_volume_mL`、`revision` | 表达操作前事实和操作后的实际变化 |

没有物理意义的属性可以省略或设为 `null`，但不得用 `0` 代替未知值。设备执行所必需的尺寸、容量或状态不得缺失。

## 容器定义

```json
{
  "object_type_id": "container.centrifuge_tube",
  "name": "离心管",
  "category": "tube",
  "properties": {
    "shape": "cylindrical",
    "bottom_shape": "conical",
    "outer_diameter_mm": 30,
    "height_mm": 115,
    "material": "polypropylene",
    "nominal_volume_mL": 50,
    "max_working_volume_mL": 45
  },
  "states": {
    "container_status": ["有盖", "无盖"],
    "sample_status": ["空", "液体", "固体", "固液混合物"]
  }
}
```

| 字段 | 说明 |
| --- | --- |
| `object_type_id` | 容器的稳定类型标识 |
| `category` | 容器分类，用于选择适用的属性和校验规则 |
| `shape`、`outer_diameter_mm`、`height_mm` | 形状和尺寸，用于装夹、定位及兼容性判断 |
| `material` | 主材质，用于工艺和耐受性判断 |
| `nominal_volume_mL`、`max_working_volume_mL` | 标称容积与最大工作容积 |
| `container_status` | 容器开闭等设备可确认状态 |
| `sample_status` | 容器中样品的设备可确认状态 |

## 操作请求中的对象

每个操作请求必须包含目标容器和其执行前状态：

```json
{
  "object": {
    "containers": [
      {
        "container_id": "container-01",
        "object_type_id": "container.centrifuge_tube",
        "before_state": {
          "container_status": "无盖",
          "sample_status": "空",
          "sample_volume_mL": 0
        },
        "capacity": {
          "max_working_volume_mL": 45,
          "remaining_volume_mL": 45
        }
      }
    ]
  }
}
```

设备或适配层必须校验容器存在、类型兼容、实际状态与请求状态一致，且容量满足操作要求。状态未知时必须返回诊断，不得以推测值继续执行。

## 操作响应中的对象

响应必须报告实际对象变化：

```json
{
  "object": {
    "changes": [
      {
        "container_id": "container-01",
        "before_state": {
          "container_status": "无盖",
          "sample_status": "空",
          "sample_volume_mL": 0
        },
        "after_state": {
          "container_status": "无盖",
          "sample_status": "液体",
          "sample_volume_mL": 0.5
        },
        "revision": "object-22"
      }
    ]
  }
}
```

只有设备确认操作完成后才可出现 `after_state`。失败、取消或结果未知时，响应必须返回当前可确认状态或明确标记未知。
