## 范围

FSP 对象分区主要说明设备能够识别或处理的实验器皿，以及运行时器皿的当前状态。目录只收录具有明确器皿、样品容纳或样品承载语义的对象；架子、槽位、抽屉、电池和设备内部安装结构不属于本目录，它们仅可作为位置、耗材或部署实现信息使用。

离心管、反应管、西林瓶、烧杯、坩埚、比色皿和多孔板属于容器；XRD 基底片、玻片、光刻片、玻碳片和质谱板等若直接承载被处理样品，可登记为承载物。`object_kind` 仅区分 `container`（容器）与 `carrier`（承载物）；容器是本规范对象模型的核心类型。

研究对象的科学身份、样品、证据与来源见[研究对象与状态](/specification/research/objects)。

## 容器类型定义

```json
{
  "object_type_id": "container.vial",
  "variant_id": "vial.flat_top.7_5mm",
  "name": "平口西林瓶",
  "object_kind": "container",
  "properties": {
    "geometry": {
      "shape": "cylindrical",
      "height_mm": 75,
      "body_outer_diameter_mm": 22.4,
      "mouth_outer_diameter_mm": 19.6
    },
    "material": {
      "primary": "glass"
    },
    "capacity": {
      "nominal_volume_mL": null,
      "max_working_volume_mL": null
    },
    "closure": {
      "supported": true,
      "type": "flat_top_cap"
    }
  },
  "states": {
    "container_status": ["有盖", "无盖"],
    "sample_status": ["空", "液体", "固体", "固液混合物"]
  }
}
```

### 读取容器状态的输入

| 输入字段 | 类型 | 作用 |
| --- | --- | --- |
| `device_id` | `string` | 指定持有对象状态的工作站 |
| `category` | `string` | 固定为 `object` |
| `object_ids[]` | `array[integer|string]` | 指定要读取的对象实例 |

该非规范性示例只填写已知的外形、尺寸和材质；未确认的容积保持 `null`。真实值必须由 FSP 设备或经确认的器皿资料提供，不能由转换程序补猜。

### 必需属性

| 字段 | 说明 |
| --- | --- |
| `object_type_id` | 稳定的对象类型标识；同一物理类别的变体共享该标识 |
| `variant_id` | 稳定的物理变体标识；尺寸、材质或口部结构不同则必须不同 |
| `name` | 面向人的名称 |
| `object_kind` | `container` 或 `carrier`；容器必须为 `container` |
| `properties.geometry` | 形状、长宽高、厚度、内外径、口径、圆角和其他可测几何量 |
| `properties.material` | 主材质及必要时的复合材质说明 |
| `properties.capacity` | 标称容积和允许工作容积，单位为 `mL` |
| `properties.layout` | 孔数、孔径等多孔容器或承载对象的布局属性 |
| `properties.closure` | 是否支持盖体及盖体类型 |
| `states` | 设备可观察或修改的状态字段和允许值 |

圆形和圆柱形容器应当描述直径；非圆形容器使用适用的长度、宽度和高度。可盛装样品或试剂的容器应当声明 `nominal_volume_mL`；设备允许加注、抽取或处理的上限应当另行声明 `max_working_volume_mL`。不可得数值使用 `null`，并在 `metadata.attribute_status` 中标为 `unmeasured` 或 `unknown`，不得猜测。

## 器皿类型目录

本目录是面向协议阅读者的通用器皿分类，不展示其他系统使用的目录主键。设备实现只声明实际支持的类型与变体；同名器皿在尺寸、材质、口部、孔位或容积不同的情况下，必须以独立 `variant_id` 声明。

多孔板的外形、孔位等可互操作尺寸已有 [ANSI/SLAS 微孔板标准](https://www.slas.org/education/ansi-slas-microplate-standards/)；FSP 不硬编码这些数值，而是要求设备在其类型定义中声明实际采用的孔位布局、外形和标准版本。

| 对象类别 | 器皿或承载物名称 | 典型变体或物理记录要求 |
| --- | --- | --- |
| 管类容器 | 离心管 | 15 mL 锥形、50 mL 锥形或圆柱变体；记录容积、高度、外径、材质和盖体 |
| 管类容器 | 反应管、耐压反应管、试管 | 记录容积、长度、直径、耐压或耐温限制和材质 |
| 管类容器 | 核磁管 | 记录长度、外径、壁厚、材质和是否带盖 |
| 瓶类容器 | 西林瓶、色谱瓶、样品瓶 | 平口、螺口、圆底等变体；记录瓶身/瓶口尺寸、容积、材质和封口类型 |
| 瓶类容器 | 试剂瓶、粉末瓶、耐热瓶、耐压瓶、浓缩瓶 | 记录容积、口径、瓶身尺寸、材质、密封和耐压/耐温限制 |
| 开口容器 | 烧杯 | 记录标称容积、口径、高度、材质和刻度精度（如适用） |
| 多孔容器 | 24 孔板、96 孔板及其他微孔板 | 记录孔数、孔位布局、孔径、单孔工作容积、外形尺寸和底部类型；采用 ANSI/SLAS 外形或孔位标准时应声明对应版本 |
| 高温或反应容器 | 坩埚、管式炉坩埚、高压釜 | 记录内外尺寸、容积（如适用）、材质、最高温度和压力限制 |
| 进样容器 | 液体料斗、固体进样料斗 | 记录入口、出口、容积或可容纳量、长宽高和适用物料形态 |
| 光学容器 | 比色皿 | 3 mL、5 mL 等变体；记录内腔尺寸、光程、容积和材质 |
| 样品承载物 | XRD 基底片、红外基底片、玻片、光刻片、玻碳片、质谱板 | 不盛装样品时标记为 `carrier`；记录平面形状、长宽或直径、厚度、材质和样品承载区域 |

## 运行时状态

`fsp/read` 读取容器当前状态：

```json
{
  "jsonrpc": "2.0",
  "id": "read-object-1",
  "method": "fsp/read",
  "params": {
    "device_id": "2002186824385539",
    "category": "object",
    "object_ids": [1, 2]
  }
}
```

| 输出字段 | 类型 | 作用 |
| --- | --- | --- |
| `container_type` | `string` | 表示本次返回的容器类型 |
| `container_count` | `integer` | 表示该类型容器总数 |
| `container_ids[]` | `array[integer|string]` | 表示本次返回的容器实例 |
| `containers[]` | `array[object]` | 保存每个容器的编号、容器状态、样品状态和体积 |
| `revision` | `string` | 用于后续状态改变请求的并发检查 |
| `diagnostics[]` | `array[object]` | 保存读取诊断 |

返回值沿用设备能力中声明的字段：

```json
{
  "result_type": "complete",
  "value": {
    "container_type": "进样瓶",
    "container_count": 2,
    "container_ids": [1, 2],
    "containers": [
      {
        "container_id": 1,
        "container_status": "无盖",
        "sample_status": "液体",
        "sample_volume": 0.5
      },
      {
        "container_id": 2,
        "container_status": "无盖",
        "sample_status": "液体",
        "sample_volume": 0.5
      }
    ],
    "revision": "7"
  },
  "diagnostics": []
}
```

## 状态规则

- 设备只能返回能力数据集中已经声明的状态字段；
- 状态读取必须包含观测时间或修订号；
- 操作产生的状态变化必须与操作定义的 `effects` 一致；
- 强制条件失败时不得提交预期新状态；
- 设备实际状态未知时必须明确返回诊断，不能假定操作成功。
