title: "对象"
description: "说明实验容器如何分类，并描述形状、容量、材质和状态。"
---

FSP 中的对象是设备能够识别、处理或观测的容器。对象描述的不是某台设备中的内部编号，而是设备操作所面对的实际实验器皿及其当前事实。

## 对象原理

FSP 使用稳定的容器类型、物理属性和当前状态，使编译/解释器、仿真器、执行器以及不同设备能够判断同一容器是否可识别、可容纳、可定位和可操作。

容器类型目录可以扩展，但每个名称必须对应明确的器皿形态。不同容量、口型、底型或材质会影响定位、夹持、容量和工艺兼容性时，应定义为不同类型或不同规格。

## 容器分类

| 分类 | 容器示例 | 重点描述的数据 |
| --- | --- | --- |
| 瓶类 | 西林瓶、色谱进样瓶、留样瓶、粉末瓶、耐热瓶、耐压瓶、耐腐蚀瓶、浓缩瓶、核磁溶剂瓶、核磁原料瓶 | 瓶身与瓶口直径、高度、底型、口型、盖型、材质、标称容积和最大工作容积 |
| 管类 | 15 mL 离心管、50 mL 离心管、试管、耐压反应管、核磁管 | 管径、高度、底型、口型、材质、标称容积、耐压或耐温范围 |
| 孔板类 | 24 孔板、96 孔板、电镜样品板、质谱样品板 | 长宽高、孔数、行列布局、单孔形状、孔径、孔深、单孔容积和板体材质 |
| 坩埚类 | 高温煅烧坩埚、XRD 坩埚、管式炉处理坩埚、管式炉反应坩埚 | 外形、口径、底径、长度、宽度、高度、材质、耐温范围和工作容积 |
| 反应容器 | 烧杯、高压釜 | 内外径、高度、开口与密封形式、材质、标称容积、最大工作容积、耐压和耐温范围 |
| 光学与表征容器 | 3 mL 比色皿、5 mL 比色皿、石英基底片、红外基底片、玻璃片、荧光玻片、光刻片、玻碳片 | 长宽厚或直径、光程、材质、表面形态、可用区域和样品承载状态 |
| 进样与转移容器 | 固体进样料斗、料斗、中转原料瓶 | 开口尺寸、长宽高、材质、容量、出口形态和当前装载状态 |

该分类用于统一语义，不限制实现只支持表中器皿。设备接口只需声明自己实际支持的容器类型和规格。

## 容器类型字段

| 字段 | 含义 | 可以填写的内容与示例 |
| --- | --- | --- |
| `object_type_id` | 稳定标识一种容器类型 | 可填 `container.centrifuge_tube.50ml`、`container.microplate.96_well`；不得使用临时目录编号 |
| `name` | 容器的规范名称 | 可填“50 mL 锥形离心管”“96 孔板”“3 mL 比色皿” |
| `category` | 容器所属分类 | 可填 `bottle`、`tube`、`microplate`、`crucible`、`reaction_vessel`、`optical_vessel`、`transfer_vessel` |
| `description` | 说明该规格与相近容器的区别 | 例如“圆锥底、螺旋盖、聚丙烯材质的 50 mL 离心管” |
| `shape` | 容器主体形状 | 可填圆柱、圆锥、长方体、正方体、平板或设备声明的复合形状 |
| `bottom_shape` | 容器底部形状 | 可填平底、圆底、锥底、U 形底、V 形底；平片类可不填 |
| `opening_shape` | 容器开口形状 | 可填圆口、方口、敞口、窄口或出口漏斗形 |
| `length_mm`、`width_mm`、`height_mm` | 容器外廓尺寸 | 96 孔板可填写长、宽、高；比色皿可填写宽度、高度和光程方向长度 |
| `outer_diameter_mm`、`inner_diameter_mm` | 主体外径与有效内径 | 50 mL 离心管可填写瓶身外径；核磁管可填写管外径和内径 |
| `opening_diameter_mm` | 瓶口或管口直径 | 用于吸液工具进入、塞盖或夹具兼容判断 |
| `thickness_mm` | 片材厚度或器壁厚度 | 石英基底片可填写片厚；耐压容器可填写壁厚 |
| `material` | 容器主体材质 | 可填玻璃、石英、聚丙烯、聚四氟乙烯、金属、氧化铝陶瓷等 |
| `surface_material` | 与样品直接接触的表面材质或涂层 | 例如玻璃主体带疏水涂层；无特殊表面时可不填 |
| `nominal_volume_mL` | 产品或规格标称容积 | 离心管可填 `15 mL` 或 `50 mL`，比色皿可填 `3 mL` |
| `max_working_volume_mL` | 实际操作允许的最大容积 | 可低于标称容积，例如 50 mL 管的最大工作容积为 `45 mL` |
| `closure_type` | 封闭形式 | 可填无盖、螺旋盖、压盖、塞盖、密封阀；也可声明支持多种盖型 |
| `well_count`、`rows`、`columns` | 孔板的孔数和布局 | 96 孔板可填 96 孔、8 行、12 列；24 孔板可填 4 行、6 列 |
| `well_shape`、`well_volume_mL` | 单孔底型、孔形和容量 | 可填圆孔、平底，单孔最大容积 `0.4 mL` |
| `temperature_range` | 容器允许的温度范围 | 坩埚、耐热瓶、高压釜可填写最低和最高允许温度 |
| `pressure_range` | 容器允许的压力范围 | 耐压瓶、高压釜、耐压反应管可填写允许工作压力 |
| `supported_states` | 设备能够确认的状态集合 | 容器状态可包括有盖、无盖、已定位、未定位；样品状态可包括空、液体、固体、混合物 |

没有物理意义的字段可以省略或设为 `null`，但不得用 `0` 代替未知值。设备执行所必需的尺寸、容量或状态不得缺失。

## 调用时的对象字段

| 字段 | 含义 | 可以填写的内容与示例 |
| --- | --- | --- |
| `container_id` | 本次操作涉及的具体容器实例 | 可填 `container-01`、`plate-03`；只在当前系统中唯一即可 |
| `object_type_id` | 实例对应的容器类型 | 例如 `container.centrifuge_tube.50ml`，用于查找尺寸和容量规则 |
| `role` | 容器在操作中的作用 | 可填目标容器、来源容器、废液容器、测量容器、中转容器 |
| `before_state` | 调用方认为的操作前状态 | 可说明有盖或无盖、空或含液、当前样品体积、是否已定位 |
| `expected_revision` | 调用方依据的对象状态版本 | 例如 `object-21`；实际版本不一致时应拒绝动作并返回冲突诊断 |
| `location` | 设备可识别的容器位置 | 可填设备工作区域、孔位、夹持位置或坐标引用；格式由设备说明 |
| `sample` | 容器内样品的可确认信息 | 可填样品标识、物态、体积、质量、浓度；未知成分不应推测 |
| `capacity` | 当前可用容量或可取样量 | 加液时填写剩余容量，取液时填写当前体积和必须保留的最小体积 |

## 返回时的对象字段

| 字段 | 含义 | 可以填写的内容与示例 |
| --- | --- | --- |
| `container_id` | 状态结果对应的容器实例 | 必须与调用中的目标或相关容器一致 |
| `before_state` | 设备执行前实际确认的状态 | 可与调用方提供的状态相同，也可用于说明发现的差异 |
| `after_state` | 操作完成后的实际状态 | 加液后可填写仍为无盖、样品变为液体、实际体积增加至 `0.498 mL` |
| `changed_fields` | 本次实际发生变化的字段 | 可填样品体积、容器开闭状态、位置或样品物态；便于调用方增量更新 |
| `revision` | 返回状态对应的新对象版本 | 成功变化后生成新修订号；未变化时保留当前修订号 |
| `observed_at` | 设备确认该状态的时间 | 使用带时区时间，避免把旧缓存当作当前状态 |
| `state_quality` | 状态的确认方式或可信程度 | 可填设备传感器确认、人工确认、推断、未知；推断值不得冒充实测值 |

## 填写示例

50 mL 锥形离心管应说明其分类为管类，形状为圆柱主体加锥底，标称容积为 `50 mL`，并填写高度、外径、材质、盖型和最大工作容积。一次加液调用中，对象信息可说明它是目标容器、当前无盖、样品体积为零、剩余容量为 `45 mL`。设备完成后返回实际体积和新的对象修订号。

96 孔板应说明外廓长宽高、8 行 12 列、孔位命名规则、单孔形状、单孔最大容积和板体材质。操作涉及某一孔时，`location` 可以填写 `A1`；对象结果应返回该孔的实际样品状态和体积，而不是只返回整块板“已处理”。

3 mL 比色皿应说明长宽高、光程、材质和最大工作容积。测量接口的对象信息可说明比色皿已定位、样品为液体且液面满足光路要求；测量本身不改变样品时，返回应明确对象状态未变化。
