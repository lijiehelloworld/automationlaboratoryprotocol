## 作用

系统分区描述设备整体，而不是某个具体实验操作。它至少包括设备身份、能力总体说明、当前状态和安全围栏。

## 状态读取

```json
{
  "jsonrpc": "2.0",
  "id": "read-system-1",
  "method": "fsp/read",
  "params": {
    "device_id": "2002186824385539",
    "category": "system"
  }
}
```

| 输入字段 | 类型 | 作用 |
| --- | --- | --- |
| `device_id` | `string` | 指定要读取的工作站 |
| `category` | `string` | 固定为 `system`，表示读取工作站整体状态 |

```json
{
  "result_type": "complete",
  "value": {
    "state": "idle",
    "available": true,
    "current_task": null,
    "capability_revision": "12",
    "observed_at": "2026-09-01T12:00:00Z"
  },
  "diagnostics": []
}
```

| 输出字段 | 类型 | 作用 |
| --- | --- | --- |
| `state` | `string` | 表示离线、空闲、忙碌、暂停、故障或维护状态 |
| `available` | `boolean` | 表示工作站当前是否接受操作 |
| `current_task` | `string` 或 `null` | 关联当前任务；空闲时为 `null` |
| `capability_revision` | `string` | 表示当前状态对应的能力版本 |
| `observed_at` | `string` | 表示状态观测时间 |
| `diagnostics[]` | `array[object]` | 提供状态异常或读取问题的结构化诊断 |

## 状态值

系统至少应当区分：

```text
offline
idle
busy
paused
fault
maintenance
```

设备无法准确判断时，可以使用 `unknown` 并返回诊断。

## 安全围栏

安全围栏用于表达设备服务必须执行的保护规则，例如：

- 设备忙碌时是否允许新任务；
- 参数是否超出物理能力；
- 当前状态是否允许目标操作；
- 操作是否与现有任务冲突；
- 是否需要人工确认；
- 故障或急停状态是否禁止执行。

安全围栏必须在设备执行前判断。自然语言实验方法、函数式技能或调用方提示不能绕过安全围栏。
