---
title: "控制"
description: "设备操作的参数、前置条件、执行结果与三段响应"
---

控制维度定义设备做什么、需要哪些参数、如何校验并如何报告执行结果。每项操作仍必须同时具备对象和系统维度。

## 操作定义

```json
{
  "operation_id": "add_liquid",
  "name": "加液",
  "description": "向指定容器加入定量液体",
  "parameters": [
    {
      "name": "source_container_id",
      "type": "string",
      "required": true,
      "description": "供液容器标识"
    },
    {
      "name": "volume_mL",
      "type": "number",
      "required": true,
      "minimum": 0.05,
      "maximum": 0.8,
      "unit": "mL",
      "description": "单次加液体积"
    }
  ],
  "preconditions": [
    "目标容器必须为无盖状态",
    "目标容器剩余容量必须大于等于加液量"
  ]
}
```

## 加液接口示例

以下是传输无关的接口载荷。HTTP 请求体、CLI 输入文件、MCP 工具输入或 SDK 参数对象均可采用同一结构。

### 输入

```json
{
  "device_id": "device-01",
  "operation_id": "add_liquid",
  "object": {
    "containers": [
      {
        "container_id": "container-01",
        "object_type_id": "container.centrifuge_tube",
        "before_state": {
          "container_status": "无盖",
          "sample_status": "空",
          "sample_volume_mL": 0
        },
        "capacity": {"remaining_volume_mL": 45}
      }
    ]
  },
  "control": {
    "parameters": {
      "source_container_id": "source-01",
      "volume_mL": 0.5
    },
    "preconditions": [
      "volume_mL 位于 0.05 至 0.8 mL",
      "容器处于无盖状态"
    ]
  },
  "system": {
    "expected_device_state": "idle",
    "expected_system_revision": "system-21",
    "execution_mode": "async",
    "preconditions": ["设备无故障", "当前没有冲突任务"],
    "safety_fences": ["目标容器容量足够", "供液容器可用"]
  }
}
```

## 强制规则

- 接口执行前必须校验对象状态、控制参数与系统条件；
- 接口响应必须返回对象实际状态、控制执行状态及系统事实；
- 安全围栏的检查结果必须逐项返回；
- 失败、取消或未知结果时，不得提交预期成功状态；
- FSP 不规定该接口在 HTTP、CLI、MCP 或 SDK 中的具体名称与路径。
