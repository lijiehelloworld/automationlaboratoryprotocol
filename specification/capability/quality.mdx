## 输入

输入是按照[能力供给与准入](/specification/capability/overview)生成的设备能力说明。

现有评估器检查：

```text
工作站名称和标题
操作描述
参数信息
初始状态
状态更新
约束规则
Frontmatter 完整性
参数约束规范
嵌套参数展开
返回值
状态转换完整性
示例完整性
```

## 准入判断

设备能力说明只有同时满足以下条件才能准入：

```text
passed == true
total_score >= threshold
```

默认样例阈值为 60。阈值来自质量评估配置，不作为所有部署不可修改的协议常量。

## 不通过与修订

评估不通过时，仍使用同一报告结构：

- `passed=false`；
- 失败项保留在 `required_checks` 或 `optional_checks`；
- `fix_instructions` 给出修订要求；
- `suggestions` 给出非阻断建议。

修订后必须重新生成完整报告，不能只修改总分。

## 对 FSP 数据的补充检查

从 FSP 生成能力说明时还应检查：

- 来源设备和修订号是否存在；
- 对象、操作和系统三个分区是否可解析；
- 操作参数和状态字段是否能够无损映射；
- 系统安全围栏是否进入说明；
- 派生说明是否遗漏 FSP 强制约束。

这些检查可以增加到现有评分配置，但输出仍使用现有报告字段。
