# 常见问题

## ALP Client 是独立服务吗？

不是。ALP Client 是集成在用户应用、自动化系统或智能体运行时中的协议客户端能力，负责发现、请求封装、版本协商、状态订阅和错误处理。

## 设备必须实现全部能力吗？

不是。设备必须实现基础协议、发现、Manifest 以及其声明能力所需的接口。Workflow 和 Device Agent 属于可选能力，只有在 Manifest 中声明后才形成协议承诺。

## `read`、`write` 和 `invoke` 有什么区别？

`read` 只读取状态；`write` 修改可写状态；`invoke` 执行已声明动作。三者共享消息、鉴权、版本、错误和追踪语义，但执行路径不同。

## Physical Resource 包含什么？

Physical Resource（物理资源）只分为 Work Object（作业对象）和 Device Supply（设备供给物料）。容器在被设备直接操作时属于 Work Object，包含关系通过字段表达，不另建第三类。

## 架构图是否规定实现方式？

不规定。架构图解释一种可行的服务内部职责划分；符合性只由规范性接口、数据结构和行为条款决定。
