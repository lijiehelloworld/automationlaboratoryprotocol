---
title: "快速开始"
description: "从 FSP 设备定义到实验程序执行的最短路径"
---

<Steps>
  <Step title="准备 FSP 设备定义">
    在设备接入配置中提供操作、对象和系统定义。
  </Step>
  <Step title="编译/解释">
    将实验目标、初始对象状态和 FSP 设备定义交给编译/解释器，取得类型化中间程序。
  </Step>
  <Step title="仿真">
    使用同一设备定义版本检查参数、状态闭合、系统围栏和完成条件。
  </Step>
  <Step title="执行">
    仅把 `simulation_status=passed` 的程序交给执行器，由执行器按 `read`、`write` 或 `invoke` 分类通过 FSP 下发。
  </Step>
  <Step title="核验结果">
    同步结果立即验证；异步操作通过系统任务查询，成功后再提交实际对象状态。
  </Step>
</Steps>

## 最小执行请求

```json
{
  "jsonrpc": "2.0",
  "id": "execute-1",
  "method": "fsp/invoke",
  "params": {
    "device_id": "device-01",
    "operation_id": "add_liquid",
    "arguments": {
      "container_id": "container-01",
      "volume_mL": 0.5
    },
    "expected_system_revision": "state-21"
  }
}
```

<Warning>
执行请求必须来自当前 FSP 设备定义和已通过的仿真结果，不得根据设备名称猜测接口或参数。
</Warning>
