ALL 社区在 [GitCode 主仓库](https://gitcode.com/mimedal/all)协作，维护规范文档、参考代码和测试，交流设备接入与不同实现之间的兼容问题。

## 参与入口

| 你想做什么 | 从哪里开始 |
| --- | --- |
| 报告文档错误、规范歧义或实现问题 | 在 [Issue](https://gitcode.com/mimedal/all/issues) 中说明问题、复现条件及预期行为 |
| 建议改变接口或协议规则 | 阅读[改进提案](/docs/proposals/about)，在 Issue 中提出方案 |
| 修正文档、补充示例或测试 | 按[贡献指南](/docs/community/contributing)提交[合并请求](https://gitcode.com/mimedal/all/pulls) |
| 反馈设备接入或互操作结果 | 在 Issue 中注明规范版本、实现差异和验证结果 |
| 查阅公开文档与参考代码 | 浏览 [GitCode 源仓库](https://gitcode.com/mimedal/all) |

讨论前请先搜索已有 Issue。同一个问题尽量集中在同一条讨论中，相关代码修改通过合并请求关联，便于后来参与者了解背景和结论。

GitHub 仓库仅作为 Mintlify 文档发布镜像。问题、提案和代码修改请统一提交到 GitCode。

## 协作约定

技术决定和发布记录的处理方式见[治理](/docs/community/governance)，讨论中的行为边界见[行为准则](/docs/community/code-of-conduct)。

公开讨论不得包含设备秘密、实验数据、个人信息或禁止公开的供应商资料。
