---
title: "行为准则"
description: "在 GitCode 的问题讨论、提案评审和合并请求中保持专业、尊重与可核查。"
---

本准则适用于 [ALL GitCode 仓库](https://gitcode.com/mimedal/all)中的 Issue、合并请求和评审评论。参与者应以专业、尊重和可验证的方式讨论问题：

- 针对设计和证据提出意见，不攻击个人或组织；
- 清楚区分事实、推断、当前实现和计划能力；
- 尊重保密、知识产权、安全和隐私边界；
- 主动披露可能影响技术判断的利益关系；
- 不发布设备秘密、漏洞利用细节或禁止公开的设备信息。

违反准则的内容可以被编辑、隐藏或移除；严重或重复违规可能导致参与权限受限。

对技术结论有异议时，请在原 Issue 或合并请求中补充依据，避免重复开帖或针对个人争论。提交修改前请阅读[贡献指南](/docs/community/contributing)，技术决定的记录方式见[治理](/docs/community/governance)。
