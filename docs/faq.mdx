## ALL 和 FSP 是什么关系？

ALL 是完整语言，包含编译/解释器、仿真器和执行器。FSP 是 ALL 内部面向设备的设备接口规则。

## 设备必须原生实现 FSP 吗？

不需要。现有 HTTP API、CLI、MCP 工具、厂商 SDK、RPC、消息接口或驱动都可由适配层映射为 FSP。

## 对象、操作和系统分别表示什么？

三者共同构成一项设备操作：对象说明操作哪个容器及其状态；操作说明做什么、参数是什么、执行前要满足什么条件；系统说明设备状态、安全限制、任务和注意事项。请求和响应都必须包含三部分。

## 异步任务属于哪个模块？

异步任务属于 FSP 系统部分。操作受理后可返回任务标识；后续状态、结果和取消信息通过系统任务返回。

## 仿真通过是否等于实验成功？

不等于。仿真只说明步骤通过了已定义的检查，不证明真实设备或样品会达到预期。执行时仍要检查容器和设备状态，并按实际测量和检查结果判断是否成功。
