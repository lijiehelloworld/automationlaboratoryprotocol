ALL 位于 AI 智能体和物理设备之间。语言引擎负责编译、仿真和执行；FSP 服务通过动作契约、能力门控和 Adapter 连接多个设备。

## 总体架构

![ALL 总体架构](/images/all-language-architecture.jpg)

## 数据流

```text
AI 智能体
  ↕
ALL 语言引擎：编译/解释器 → 仿真器 → 执行器
  ↕
FSP 服务：动作契约 → 能力门控 → Adapter
  ↕
设备接口：操作 + 对象 + 系统
  ↕
多个设备
```

设备由适配层接入，保留既有接口；每次操作都必须返回实际对象状态、操作执行情况和系统状态。
