---
title: "名词解释"
description: "快速查询 ALL、FSP、对象、操作、系统等术语。"
---

| 名称 | 说明 |
| --- | --- |
| AI 原生实验室语言（ALL） | 把实验目标写成可检查、可执行步骤的语言。 |
| ALL 语言引擎 | 负责生成步骤、仿真检查和实际执行的程序。 |
| 编译/解释器 | 把 FSP 设备定义和实验目标转换为参数类型明确的执行步骤。 |
| 仿真器 | 在不影响真实设备的测试环境中验证参数、状态变化、系统安全限制和完成条件。 |
| 执行器 | 将通过仿真的中间程序交给 FSP 并核验实际结果。 |
| FSP | 规定设备调用的输入、输出和处理规则，不限定 URL、命令名或传输方式。 |
| 操作契约 | 一项操作的参数、结果和执行规则。名称所属范围、`operation_id` 和版本共同确定使用哪份定义。 |
| 对象 | 操作涉及的容器及其类型、形状、尺寸、材质、容积和状态。 |
| 操作维度 | 厂商设备接口必须提供的操作信息，包含操作标识、参数、约束、实际执行状态和诊断。 |
| 系统 | 设备状态、安全限制、执行模式、异步任务和注意事项。 |
| 系统任务 | 一次操作的执行记录，可用任务编号查询进度、结果或申请取消。 |
| 诊断 | 与对象、参数、操作或系统状态关联的结构化问题说明。 |
| 设备能力描述 | 说明某台设备实现了哪些操作、有哪些限制、配置和验收是否完成。 |
| Function Skill | 根据操作和设备定义生成的说明，供规划程序或 AI 阅读；不能代替现场检查和验收。 |
| 完成范围 | “成功”具体表示什么：命令收到、设置生效、设备动作完成，还是样品达到要求。 |
| 完成证据 | 用来确认操作完成的读数或检查记录，要写清任务、对象、来源和时间；不能使用计划值或模型猜测。 |
| 未知结果 | 无法确认动作结果或停止状态，需暂停使用相关设备和容器并核实；不等于失败，也不授权重发。 |
| 幂等键 | 用于识别同一次操作重试的键，防止重复执行；不是每次通信的请求编号。 |
