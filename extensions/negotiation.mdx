# 扩展协商

扩展协商发生在 `server/discover` 阶段。调用方提交自己支持的扩展及版本范围，服务端返回本次请求可使用的交集。

```json
{
  "protocol_version": "2026-08-31",
  "client_capabilities": {
    "extensions": {
      "org.example.capability": {
        "versions": ["2026-08-31"]
      }
    }
  }
}
```

## 规则

1. 服务端必须拒绝其标记为必需、但调用方不支持的扩展。
2. 可选扩展无法协商时，双方继续使用基础协议。
3. 每个请求必须携带实际使用的协议版本；扩展请求应携带已协商的扩展版本。
4. 服务端不得依据隐藏会话推断扩展状态。
5. 扩展协商结果变化时，服务端应更新发现结果的 `revision`。
