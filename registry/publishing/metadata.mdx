---
title: "发布元数据"
description: "all-server.json 的结构和字段"
---

发布者使用 `all-server.json` 描述可发现的 ALL 服务。该文件是注册元数据，不是设备能力清单，也不得包含凭据或设备实时状态。

```json
{
  "schema_version": "2026-08-31",
  "name": "org.example/service",
  "title": "示例自动化服务",
  "description": "设备无关的服务说明",
  "version": "1.0.0",
  "protocol_versions": ["2026-08-31"],
  "publisher": {
    "namespace": "org.example"
  },
  "connections": [
    {
      "type": "https",
      "url": "https://example.org/all",
      "protected_resource_metadata": "https://example.org/.well-known/oauth-protected-resource"
    }
  ],
  "capabilities": {
    "system": true,
    "objects": true,
    "operations": true,
    "workflows": true
  }
}
```

## 必需字段

| 字段 | 说明 |
| --- | --- |
| `schema_version` | 注册元数据结构版本。 |
| `name` | 命名空间内唯一且稳定的服务名称。 |
| `version` | 本条记录所描述的服务版本。 |
| `protocol_versions` | 服务声明支持的 ALL 协议版本。 |
| `publisher.namespace` | 已验证的发布者命名空间。 |
| `connections` | 至少一个 HTTPS ALL 端点及其 OAuth 受保护资源元数据地址。 |

能力摘要只用于检索。调用方必须以实时 `system/discover` 和 `system/get_manifest` 为最终依据。
