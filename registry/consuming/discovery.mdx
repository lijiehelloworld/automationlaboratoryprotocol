# 发现服务

调用方或聚合服务可以按名称、协议版本、连接类型和能力摘要查询注册记录。

发现流程分为两个阶段：

1. 从注册中心获得候选 ALP Server 的元数据和连接地址。
2. 直接连接候选服务，通过 `server/discover` 和 `devices/get_manifest` 获取实时能力。

注册中心结果不得替代第二阶段。能力摘要可能过期，设备可能离线，部署权限也可能限制实际可用能力。

## 缓存

消费者应遵守注册接口返回的缓存控制信息。缓存过期后必须重新获取记录；安全撤回和命名空间撤销信息应优先于普通缓存。
