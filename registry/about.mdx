---
title: "关于注册中心"
description: "ALL 服务元数据的发现与分发"
---

ALL 注册中心用于发布和发现 ALL 服务的标准化元数据。注册中心保存描述信息和连接信息，不托管设备驱动，也不代替 ALL 服务执行设备操作。

注册中心提供：

- 服务名称与命名空间管理；
- 协议版本、端点和部署类型描述；
- 可发现能力的摘要；
- 发布者身份验证信息；
- 面向调用方和聚合服务的查询接口。

<Info>
注册中心属于独立的生态服务。ALL 客户端可以直接连接已知 ALL 服务端，不要求经过注册中心。
</Info>

## 角色关系

| 角色 | 职责 |
| --- | --- |
| 发布者 | 提交并维护服务元数据，证明命名空间所有权。 |
| 注册中心 | 校验、存储和查询元数据。 |
| 聚合服务 | 同步注册记录并提供筛选、评价或私有目录。 |
| 调用方 | 发现候选服务，随后直接与 ALL 服务端完成协议交互。 |

## 信任边界

注册记录只能证明元数据发布者与命名空间之间的关系，不能证明设备适合某个实验，也不能代替调用方执行安全评估。
