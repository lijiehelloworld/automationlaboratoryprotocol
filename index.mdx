Automation Laboratory Language（ALL，自动化实验室语言）把科学目标、研究对象、函数式实验方法和物理设备连接成可计算、可验证、可追溯的实验闭环。

Function State Protocol（FSP，函数状态协议）位于 ALL 内部，负责以对象、操作、系统三类数据统一发现和调用实验室设备。设备可以保留原有 API、SDK 或驱动，通过适配器接入 FSP。

## 设备接入原则

- 工作站只需把对象、操作和系统说清楚；
- 对象只描述设备可识别的容器及状态；
- 操作说明函数、参数、约束、状态变化和返回值；
- 系统说明总体能力、运行状态和安全围栏；
- FSP 不要求设备采用统一底层接口；
- 顺序、有限循环、条件、并行汇合和受保护区间由函数式实验方法表达。
