Automation Laboratory Language（ALL）只划分为四个协议模块：对象、操作、Workflow 和系统。架构图用于说明模块关系，不规定服务端内部如何部署。

<Note>
对象模块只表示研究对象。每个研究对象固定包含身份、样品、容器、证据、来源与可扩展字段。
</Note>

## 模块关系

1. 系统模块提供能力发现、状态、事件、权限、安全、版本和审计。
2. 对象模块定义研究对象的身份、样品、容器、证据、来源、位置与包含关系。
3. Workflow 模块把一个或多个状态转换组织成可校验、可版本化、可运行的流程，并支持五类组合算子。
4. 操作模块负责读取、写入、调用和返回具备诊断的状态转换结果。
5. Workflow 发起操作，操作作用于研究对象；确认后的结果更新对象状态并产生证据、来源记录和系统事件。

## 最小交互逻辑

```text
系统发现与授权
  → 读取或定位研究对象
  → 直接执行操作，或由 Workflow 组织多个操作
  → 返回结果并更新系统状态与事件
```
