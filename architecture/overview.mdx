Automation Laboratory Language（ALL）只划分为四个协议模块：对象、操作、Workflow 和系统。架构图用于说明模块关系，不规定服务端内部如何部署。

<Note>
对象模块只表示作业对象。容器、样品、物料和耗材根据其在作业中的角色统一作为作业对象表达，不再设置独立耗材模块。
</Note>

## 模块关系

1. 系统模块提供能力发现、状态、事件、权限、安全、版本和审计。
2. 对象模块定义作业对象的标识、类型、状态、位置、包含关系和关联关系。
3. Workflow 模块把一个或多个操作组织成可校验、可版本化、可运行的流程。
4. 操作模块负责读取、写入、调用和返回执行结果。
5. Workflow 发起操作，操作作用于作业对象，执行结果更新系统状态并产生事件。

## 最小交互逻辑

```text
系统发现与授权
  → 读取或定位作业对象
  → 直接执行操作，或由 Workflow 组织多个操作
  → 返回结果并更新系统状态与事件
```
