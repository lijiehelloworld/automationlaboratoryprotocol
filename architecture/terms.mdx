---
title: "名词解释"
description: "ALL、FSP、语言引擎和设备接口术语"
---

| 名称 | 说明 |
| --- | --- |
| 自动化实验室语言（ALL） | 连接实验目标、可验证程序与物理设备的自动化实验室语言。 |
| ALL 语言引擎 | 编译/解释器、仿真器和执行器组成的程序处理环境。 |
| 编译/解释器 | 把 FSP 设备定义和实验意图转换为类型化中间程序。 |
| 仿真器 | 在隔离状态中验证参数、状态变化、系统围栏和完成条件。 |
| 执行器 | 将通过仿真的中间程序交给 FSP 并核验实际结果。 |
| FSP | ALL 内部面向已配置设备的接口语义规范；不限定 URL、命令名或传输方式。 |
| 操作 | 设备可执行或可观测的具体接口，以 `operation_id` 标识。 |
| 对象 | 操作涉及的容器及其类型、形状、尺寸、材质、容积和状态。 |
| 控制 | 操作参数、范围、枚举、执行前置条件、实际执行状态和诊断。 |
| 系统 | 设备状态、安全围栏、执行模式、异步任务和注意事项。 |
| 系统任务 | 长时间操作产生的运行实例，提供进度、结果与取消语义。 |
| 诊断 | 与对象、参数、操作或系统状态关联的结构化问题说明。 |
