---
title: "名词解释"
description: "ALL 四个核心模块的名称与职责"
---

| 名称 | 说明 |
| --- | --- |
| Automation Laboratory Language（ALL） | 面向实验室设备能力、作业对象和流程执行的通信协议。 |
| 系统 | 提供能力发现、状态、事件、权限、安全、版本和审计。 |
| 对象 | 统一描述作业对象及其标识、类型、状态、位置和关系。 |
| 作业对象 | 被读取、写入、操作、处理、检查、测量或测试的物理实体。 |
| 操作 | 对作业对象或设备执行读取、写入或调用，并返回结构化结果。 |
| 读取 | 获取对象或系统状态，不执行会改变物理状态的动作。 |
| 写入 | 修改允许写入的状态，并经过权限、约束和并发校验。 |
| 调用 | 执行系统已经声明的设备动作。 |
| Workflow（工作流） | 把一个或多个操作组织成可校验、可版本化和可运行的流程。 |
