# 名词解释

| 英文名称 | 中文名称 | 说明 |
| --- | --- | --- |
| Automation Laboratory Protocol (ALP) | 自动化实验室协议 | 调用方与自动化设备服务之间的通信协议。 |
| Caller | 调用方 | 使用设备能力的用户应用、自动化系统或智能体运行时。 |
| ALP Client | ALP 客户端 | 集成在调用方内部的协议能力，不是独立服务。 |
| ALP Server | ALP 服务端 | 对外提供发现、读取、写入、调用、资源和可选扩展接口。 |
| Capability Discovery | 能力发现 | 协商版本并获得服务、设备和可选能力清单。 |
| Manifest | 能力清单 | 描述设备身份、属性、动作、资源类型、Schema 和可选能力的文档。 |
| Device Model | 设备模型 | 设备能做什么的类型定义，包括属性、动作和资源类型。 |
| State Management | 状态管理 | 管理设备当前实例值、资源实例、修订号、操作和事件。 |
| Runtime Plane | 运行时平面 | 处理实时读取、写入、调用、状态和资源操作。 |
| Capability Plane | 能力平面 | 提供发现、Manifest 和静态能力定义。 |
| read | 读取 | 获取属性、状态或事件，不执行设备动作。 |
| write | 写入 | 修改可写状态，并受 Schema、权限、约束和并发控制保护。 |
| invoke | 调用 | 执行设备模型中声明的动作。 |
| Physical Resource | 物理资源 | 与设备运行相关物理实体的统一模型。 |
| Work Object | 作业对象 | 被设备直接操作、处理、检查、测量或测试的实体。 |
| Device Supply | 设备供给物料 | 运行中会消耗、损耗、排出、替换或需要补充的物料与物品。 |
| Workflow | 工作流 | 设备内置或推荐的能力组合模板，不能绕过底层安全规则。 |
| Device Agent | 设备智能体 | 设备可选提供的规划和调用能力，只能使用已授权、已声明的 ALP 能力。 |
| Execution & Safety | 执行与安全 | 负责 Schema、权限、约束、锁、幂等和审计校验。 |
| Driver | 驱动 | 将协议层请求映射为设备能够执行的底层操作。 |
| Physical Device | 物理设备 | 实际执行操作并产生状态变化的设备实体。 |
