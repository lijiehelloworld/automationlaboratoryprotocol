---
title: "名词解释"
description: "ALL 四个核心模块的名称与职责"
---

| 名称 | 说明 |
| --- | --- |
| Automation Laboratory Language（ALL） | 面向实验室设备能力、研究对象和流程执行的通信协议。 |
| 系统 | 提供能力发现、状态、事件、权限、安全、版本和审计。 |
| 对象 | 统一描述研究对象及其身份、样品、容器、证据和来源。 |
| 研究对象（Research Object） | 被读取、写入、操作、处理、检查、测量或测试，并随状态转换演化的可追溯实体。 |
| 身份（identity） | 研究对象的持久标识与显示信息。 |
| 样品（sample） | 样品身份、组成、相态、质量、体积或其他量。 |
| 容器（container） | 容器类型、标识、几何/容量、封闭状态、位置与包含关系。 |
| 证据（evidence） | 观测值、测量结果或数据产物引用。 |
| 来源（provenance） | 研究对象的登记、观测、操作提交和更正记录。 |
| 操作 | 工作站绑定的状态转换；对研究对象或系统执行读取、写入或调用并返回结构化结果和诊断。 |
| 读取 | 获取对象或系统状态，不执行会改变物理状态的动作。 |
| 写入 | 修改允许写入的状态，并经过权限、约束和并发校验。 |
| 调用 | 执行系统已经声明的设备动作。 |
| Workflow（工作流） | 把一个或多个操作组织成可校验、可版本化和可运行的流程。 |
| 顺序、有限循环、条件分支、并行汇合、受保护区间 | 工作流唯一允许的五类组合算子。 |
