---
title: "名词解释"
description: "ALL 语言引擎、FSP 和设备接口术语"
---

| 名称 | 说明 |
| --- | --- |
| 自动化实验室语言（Automation Laboratory Language，ALL） | 连接实验目标、可验证程序与物理设备的自动化实验室语言。 |
| ALL 调用方 | 集成在用户应用、自动化系统或智能体中的协议调用能力。 |
| ALL 语言引擎 | 由编译/解释器、仿真器和执行器组成的程序处理环境。 |
| 编译/解释器 | 把 FSP 设备定义和实验意图转换为类型化函数与中间程序。 |
| 仿真器 | 在隔离状态中检查参数、状态转换、系统围栏和完成条件。 |
| 执行器 | 把通过仿真的程序转换为 FSP 请求并核验实际结果。 |
| FSP（函数状态协议） | ALL 内部面向已配置设备的远程通信协议。 |
| FSP 适配器 | 把设备既有 API、SDK 或驱动映射为 FSP 语义的组件。 |
| 操作 | 设备公开的具体接口，包含标识、参数、分类、返回值和状态变化。 |
| 对象 | 操作涉及的容器及其类型、形状、尺寸、材质、容积和状态。 |
| 系统 | 设备状态、可用性、安全围栏、异步任务和结果验证规则。 |
| 请求分类 | `read`、`write` 或 `invoke`，决定操作适用的最低安全约束。 |
| 中间程序 | 编译/解释器输出、供仿真器和执行器共同使用的类型化步骤表示。 |
| 系统任务 | 长时间操作产生的异步运行实例，具有进度、结果和取消语义。 |
| 诊断 | 与请求、步骤、参数路径或设备状态关联的结构化问题说明。 |
| 驱动 | 把适配器调用转换为设备底层指令的实现。 |
